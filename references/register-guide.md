# 문서 기능과 종결어미

원문 말투와 서법을 먼저 보존합니다. 아래는 어미가 섞여 있어 선택이 필요한 경우의 기본값이며 이미 자연스럽고 일관된 문체를 바꾸는 근거가 아닙니다.

| 문서·위치 | 조정이 필요할 때의 기본값 |
|---|---|
| 보고서·로드맵·README의 설명 | `~합니다` 또는 원문의 일관된 설명체 |
| 논문·본인용 연구 노트 | 학술 `~다`체 또는 원문의 개조식 |
| 독자에게 하는 명령 | 원문과 독자에 맞는 `~하십시오`, `~하세요` |
| 의무·요건 | `~해야 합니다` 등 원문의 의무 강도 유지 |
| 표·체크리스트 | 짧은 문장 또는 명사형. 행동·조건이 생략되지 않는 쪽 선택 |
| 강의·발표자료 | 자연스러운 구어체·질문·시연 예고 유지 |
| 제목 | 내용이 드러나는 표현. 명사구 기본, 실제 질문·절차 예고 허용 |
| 캡션·접근성 라벨·안내 문자열 | 해당 문구의 기능에 맞는 짧은 설명. 본문과 어미가 달라도 자연스러우면 유지 |

- `~한다`가 세 번 이어졌다는 이유만으로 바꾸지 않습니다. 내용 없는 원칙 나열인지 판단합니다.
- 명령·의무·설명이 섞인 목록은 그 차이를 보존합니다. 어미를 통일하려고 평서를 명령으로 바꾸지 않습니다.
- 표의 명사형에서도 `미확인`, `불가`, `금지`는 서로 다른 뜻입니다. 서로 치환하지 않습니다.
- 해석이 필요한 캡션도 원문의 정당한 기능이면 유지합니다. 문체 교정만 요청받았을 때 내용을 다른 절로 옮기는 구조 개편까지 강제하지 않습니다.
- 판단·가정 표지는 보존합니다. 원문에 없는 판단자·조건·이유는 추가하지 않습니다.
