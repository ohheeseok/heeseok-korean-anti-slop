# Layer 1. 구조적 번역투 제거

영어 문장 구조를 그대로 옮긴 흔적과, 내용 없이 문장을 무겁게 만드는 한자어·서식 습관을
고칩니다. 같은 표현이라도 실제 의미를 담고 있으면 남깁니다. 일괄 치환하지 마십시오.

## L1-1. 장황한 조사·후치사

| 패턴 | 교정 | 남기는 경우 |
|---|---|---|
| `~을 통해` | `~로`, `~해서`, 동사로 직접 연결 | 실제 경로·중개 과정을 뜻할 때(`API를 통해 전달`) |
| `~에 있어서`, `~함에 있어` | `~에서`, `~할 때` | 거의 없음 |
| `~에 의해` + 피동 | 행위자를 주어로(`AI에 의해 생성된` → `AI가 만든`) | 행위자가 불분명하고 과정 자체가 주제일 때 |
| `~에 대해` + 행위 동사 | 목적격 조사로(`오류에 대해 분석` → `오류를 분석`) | 주제를 소개할 때(`이 방법에 대해 설명합니다`) |
| `~와 관련하여`, `~에 기반하여` | `~에`, `~로`, `~을 보고` | 법률·규정 인용 |

## L1-2. 이중 피동과 수동태

- `~되어진다`, `~지게 된다` → 단일 피동이나 능동으로 고칩니다.
- `평가되었다`, `활용되어 왔다`처럼 행위자를 감추는 수동태는 행위자가 분명하면 능동으로 바꿉니다(`KatFish로 평가하였다`).

## L1-3. 한자어 추상명사 체인

`고도화`, `효율성 제고`, `역량 강화`, `기반 마련`, `체계 구축`, `방향성`, `측면`, `요소`처럼
행위나 대상을 감추는 명사가 2개 이상 이어지면 실제 행위로 풉니다.

- 전: 분류 체계 고도화를 통해 처리 시간을 크게 개선했습니다.
- 후: 분류 체계를 개선해 처리 시간을 크게 줄였습니다.
- 편집 메모: 구체적인 개선 방법과 시간 수치는 원문에 없으므로 추가하지 않습니다.

추상명사를 다른 추상명사로 바꾸지 마십시오. 원문에서 확인되는 행위와 대상으로 바꿉니다. 수치는 원문에 있을 때만 사용합니다.
`~적`, `~성`, `~화`가 한 문단에 몰려 있으면 일부를 동사·형용사로 되돌립니다.

## L1-4. 속격 연쇄

`A의 B의 C`처럼 `의`가 연달아 붙으면 영어 of-구 직역일 가능성이 큽니다. 수식 관계를
유지하면서 동사구로 풉니다.

- 전: 기업의 데이터의 안전한 관리의 효율성
- 후: 기업 데이터를 안전하게 관리하는 효율

## L1-5. 가짜 대조

`단순히 A가 아니라 B다`, `A를 넘어 B로`, `A에서 B로`가 반복되거나 A를 아무도 주장하지
않았는데 대조를 세우면 B만 직접 씁니다. 사람이 쓴 글에서도 대조는 쓰이므로 한 번만 쓰인
정당한 대조는 남깁니다. 교정 중에 새 대조를 만들지 마십시오.

## L1-6. 훈계형 결말과 결산어

- 문단 끝의 `~해야 할 때입니다`, `~가 중요합니다`, `시사하는 바가 큽니다`, `주목할 만합니다`처럼 정보 없는 당위·평가 문장은 지웁니다.
- `결론적으로`, `따라서`, `이를 통해`, `요약하면`, `결국`은 논리 관계나 요약 기능이 중복될 때만 줄입니다. 실제 인과·결론을 표시하면 횟수와 관계없이 유지합니다.
- `~하는 이유다`, `~라는 점이다`, `핵심은 ~이다` 같은 도치·분열문은 주어–서술어를 바로 잇는 문장으로 고칩니다.
- `과제도 남아 있다`, `한계도 분명하다` 같은 문패 문장은 지우고 실제 과제를 첫 문장으로 씁니다.

## L1-7. 연결어미 뒤 쉼표

`~하고,`, `~하며,`, `~하지만,`, `~해서,`, `~므로,` 뒤의 쉼표는 한국어 사람 글에서 드뭅니다.
불필요한 쉼표를 지우거나 문장을 나눕니다. 문장 경계·삽입절을 구분하는 데 필요한 쉼표는 유지합니다. 횟수 증감만으로 교정의 성공·실패를 판정하지 않습니다.

## L1-8. 반복 어휘

| 패턴 | 교정 |
|---|---|
| `해당`, `이러한`, `본 ~`이 한 단락에 여러 번 | `그`, `이`, 구체 명사로 바꾸거나 삭제 |
| `다양한`, `포괄적인`, `혁신적인`, `획기적인` | 원문에 근거가 있을 때만 구체 수나 성질로 |
| `활용`, `도모`, `모색`, `극대화` | `사용`, `찾기`, `최대로` |
| `~할 수 있습니다`가 한 문단에 4회 이상 | 일부만 다른 표현으로 바꾸고 단정으로 바꾸지 않음 |
| `~것이다`, `~라는 것입니다` 종결 | `~다`, `~입니다`로 직접 종결 |

## L1-9. 서식 남용

- 문장마다 대시(—)로 부가 설명을 붙이면 쉼표, 괄호, 별도 문장으로 나눕니다.
- 강조용 따옴표, 문장마다 볼드, 문장 머리의 이모지는 지웁니다.
- `1) 2) 3)` 나열과 `첫째·둘째·셋째`가 본문 흐름을 끊으면 문장으로 녹입니다. 학술 기여 나열처럼 의도된 열거는 남깁니다.

## L1-10. 있다·것·수와 연결어의 보존 판단

이 표현들은 금지어가 아닙니다. 뜻을 유지하면서 중복되는 부분만 줄입니다.

- `진행하고 있다`의 진행 상태, `자료가 있다`의 존재, `유지되고 있다`의 지속을 보존합니다. 모두 `진행한다`로 바꾸지 않습니다.
- `것`이 대상을 가리키거나 추정을 표시하면 유지합니다. `측정한 것만 포함`의 범위를 보존하고 `실패한 것 같다`를 `실패했다`로 바꾸지 않습니다.
- `수`가 가능성·능력·허용을 나타내면 유지합니다. `실패할 수 있다`를 `실패한다`로 바꾸지 않습니다.
- `분석을 수행하는 것입니다`처럼 설명을 겹쳐 놓은 표현은 문맥상 같은 뜻이면 `분석합니다`로 줄입니다.
- `따라서`, `하지만`, `다만`은 인과·대조·예외를 전달하면 유지합니다. 반복 횟수만으로 삭제하지 않습니다.
- 줄인 뒤 시제·진행 상태·가능성·조건·예외를 원문과 대조하고 의미가 달라지면 복원합니다.

## L1-11. 조작 대상이 불분명한 지시어

강의·실습 자료의 `얘`, `그 자리`, `여기까지`가 실제 도구·기능·작업 범위를 대신하면 앞뒤 문맥에서 대상을 확인합니다. 화면에서 바로 가리키는 지시어와 시연용 대화 인용은 구분합니다. 판정·예외·예시는 [강의 자료 지침](lecture-prose.md)의 L1-11을 따릅니다.

## L1-12. 기술 해설의 포괄적 해결·보장 표현

한 가지 변경으로 모든 난점이 해결된다는 결론, 정확한 일대일 대응, 구조적 보장, 별도 장치 없이 얻어진다는 요약은 본문의 조건·추가 설계·증거 종류와 대조합니다. 주장을 임의로 낮추지 말고 [기술 해설 지침](technical-explanation.md)의 L1-12를 따릅니다. L1-5의 `A하지 말고 B하라`도 실제 기술적 대조인지 설명 수준을 섞은 구호인지 문맥에서 판단합니다.
