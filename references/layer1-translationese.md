# Layer 1. 구조적 번역투 제거

영어 문장 구조를 그대로 옮긴 흔적과, 내용 없이 문장을 무겁게 만드는 한자어·서식 습관을
고칩니다. 같은 표현이라도 실제 의미를 담고 있으면 남깁니다. 일괄 치환하지 마십시오.

## L1-1. 장황한 조사·후치사

| 패턴 | 교정 | 남기는 경우 |
|---|---|---|
| `~을 통해` | `~로`, `~해서`, 동사로 직접 연결 | 실제 경로·중개 과정을 뜻할 때(`API를 통해 전달`) |
| `~에 있어서`, `~함에 있어` | `~에서`, `~할 때` | 거의 없음 |
| `~에 의해` + 피동 | 행위자를 주어로(`AI에 의해 생성된` → `AI가 만든`) | 행위자가 불분명하고 과정 자체가 주제일 때 |
| `~에 대해` + 행위 동사 | 목적격 조사로(`오류에 대해 분석` → `오류를 분석`) | 주제를 소개할 때(`이 방법에 대해 설명합니다`) |
| `~와 관련하여`, `~에 기반하여` | `~에`, `~로`, `~을 보고` | 법률·규정 인용 |

## L1-2. 이중 피동과 수동태

- `작성되어진다`처럼 불필요한 이중 피동은 `작성된다`로 고칩니다. `~게 된다`는 변화·결과를 나타낼 수도 있으므로 형태만 보고 없애지 않습니다.
- `평가되었다`, `활용되어 왔다` 같은 수동태는 원문에 행위자가 명시되어 있고 문장의 초점도 유지될 때 능동으로 바꿀 수 있습니다. 행위자·평가 도구를 추측해 보충하지 않습니다.

## L1-3. 한자어 추상명사 체인

`고도화`, `효율성 제고`, `역량 강화`, `기반 마련`, `체계 구축`, `방향성`, `측면`, `요소`처럼
행위나 대상을 감추는 명사가 2개 이상 이어지면 실제 행위로 풉니다.

- 전: 분류 체계 고도화를 통해 처리 시간을 크게 개선했습니다.
- 후: 분류 체계를 개선해 처리 시간을 크게 줄였습니다.
- 편집 메모: 구체적인 개선 방법과 시간 수치는 원문에 없으므로 추가하지 않습니다.

추상명사를 다른 추상명사로 바꾸지 마십시오. 원문에서 확인되는 행위와 대상으로 바꿉니다. 수치는 원문에 있을 때만 사용합니다.
`~적`, `~성`, `~화`가 한 문단에 몰려 있으면 일부를 동사·형용사로 되돌립니다.

## L1-4. 속격 연쇄

`A의 B의 C`처럼 `의`가 연달아 붙으면 영어 of-구 직역일 가능성이 큽니다. 수식 관계를
유지하면서 동사구로 풉니다.

- 전: 기업의 데이터의 안전한 관리의 효율성
- 후: 기업 데이터를 안전하게 관리할 때의 효율

## L1-5. 가짜 대조

`단순히 A가 아니라 B다`, `A를 넘어 B로`, `A에서 B로`가 반복되거나 A를 아무도 주장하지
않았는데 수사용 대조를 세우면 B를 직접 설명할 수 있는지 봅니다. 실제 부정·배제·한정 정보가 있으면 보존합니다. 정당한 대조는 반복되더라도 필요한 관계를 보존합니다. 교정 중에 새 대조를 만들지 마십시오.

## L1-6. 훈계형 결말과 결산어

- 문단 끝의 `~해야 할 때입니다`, `~가 중요합니다`, `시사하는 바가 큽니다`, `주목할 만합니다`가 앞 내용을 되풀이하는 수식이면 줄입니다. 새 의무·평가·조건을 전달하면 그 정보를 남깁니다.
- `결론적으로`, `따라서`, `이를 통해`, `요약하면`, `결국`은 논리 관계나 요약 기능이 중복될 때만 줄입니다. 실제 인과·결론을 표시하면 횟수와 관계없이 유지합니다.
- `~하는 이유다`, `~라는 점이다`, `핵심은 ~이다` 같은 도치·분열문은 주어–서술어를 바로 잇는 문장으로 고칩니다.
- `과제도 남아 있다`, `한계도 분명하다` 같은 문패 문장은 지우고 실제 과제를 첫 문장으로 씁니다.

## L1-7. 연결어미 뒤 쉼표

`~하고,`, `~하며,`, `~하지만,`, `~해서,`, `~므로,`처럼 연결어미마다 쉼표를 붙이는 습관을 검토합니다.
불필요한 쉼표를 지우거나 문장을 나눕니다. 문장 경계·삽입절을 구분하는 데 필요한 쉼표는 유지합니다. 횟수 증감만으로 교정의 성공·실패를 판정하지 않습니다.

## L1-8. 반복 어휘

| 패턴 | 교정 |
|---|---|
| `해당`, `이러한`, `본 ~`이 한 단락에 여러 번 | 지칭 대상을 확인해 구체 명사로 바꾸거나 중복만 삭제. 선행 대상이 없는 다른 지시어로 교체하지 않음 |
| `다양한`, `포괄적인`, `혁신적인`, `획기적인` | 원문에 근거가 있을 때만 구체 수나 성질로 |
| `활용`, `도모`, `모색`, `극대화` | `사용`, `찾기`, `최대로` |
| `~할 수 있습니다`가 한 문단에 4회 이상 | 일부만 다른 표현으로 바꾸고 단정으로 바꾸지 않음 |
| `~것이다`, `~라는 것입니다` 종결 | 강조를 겹친 표현이면 직접 종결. 미래·예측·추정·설명 초점이 달라지면 유지 |

## L1-9. 서식 남용

- 문장마다 대시(—)로 부가 설명을 붙이면 쉼표, 괄호, 별도 문장으로 나눕니다.
- 뜻 없이 강조만 겹치는 따옴표·볼드·이모지는 줄입니다. 실제 인용·용어 언급·상태 구분 기능은 보존합니다. 문체 교정을 디자인 개편으로 확대하지 않습니다.
- `1) 2) 3)` 나열과 `첫째·둘째·셋째`가 본문 흐름을 끊으면 문장으로 녹입니다. 학술 기여 나열처럼 의도된 열거는 남깁니다.

## L1-10. 있다·것·수와 연결어의 보존 판단

이 표현들은 금지어가 아닙니다. 뜻을 유지하면서 중복되는 부분만 줄입니다.

- `진행하고 있다`의 진행 상태, `자료가 있다`의 존재, `유지되고 있다`의 지속을 보존합니다. 모두 `진행한다`로 바꾸지 않습니다.
- `것`이 대상을 가리키거나 추정을 표시하면 유지합니다. `측정한 것만 포함`의 범위를 보존하고 `실패한 것 같다`를 `실패했다`로 바꾸지 않습니다.
- `수`가 가능성·능력·허용을 나타내면 유지합니다. `실패할 수 있다`를 `실패한다`로 바꾸지 않습니다.
- `분석을 수행하는 것입니다`처럼 설명을 겹쳐 놓은 표현은 문맥상 같은 뜻이면 `분석합니다`로 줄입니다.
- `따라서`, `하지만`, `다만`은 인과·대조·예외를 전달하면 유지합니다. 반복 횟수만으로 삭제하지 않습니다.
- 줄인 뒤 시제·진행 상태·가능성·조건·예외를 원문과 대조하고 의미가 달라지면 복원합니다.

## L1-11. 지칭 대상이 불분명한 지시어

강의·실습 자료의 `얘`, `그 자리`, `여기까지`가 실제 도구·기능·작업 범위를 대신하면 앞뒤 문맥에서 대상을 확인합니다. 화면에서 바로 가리키는 지시어와 시연용 대화 인용은 구분합니다. 판정·예외·예시는 [강의 자료 지침](lecture-prose.md)의 L1-11을 따릅니다.

## L1-12. 기술 해설의 포괄적 해결·보장 표현

한 가지 변경으로 모든 난점이 해결된다는 결론, 정확한 일대일 대응, 구조적 보장, 별도 장치 없이 얻어진다는 요약은 본문의 조건·추가 설계·증거 종류와 대조합니다. 주장을 임의로 낮추지 말고 [기술 해설 지침](technical-explanation.md)의 L1-12를 따릅니다. L1-5의 `A하지 말고 B하라`도 실제 기술적 대조인지 설명 수준을 섞은 구호인지 문맥에서 판단합니다.

`X가 병목입니다`가 반복되는 진단도 L1-12의 검토 대상입니다. 용어 자체의 빈도보다 실제 제약 설명을 대신하는지 판단합니다. [기술 해설 지침](technical-explanation.md)의 병목 진단 기준을 따릅니다.

## L1-13. 상호영향 선언과 통합 결론의 반복

`따로 놀지 않는다 → 영향 사례 → 그래서 함께 본다`로 구성된 정형 문단은 전체 선언과 결론이 같은 말을 반복하는지 확인합니다. 단순 강조용 따옴표를 줄이되 실제 관계·검토 목적·항목 수는 보존합니다. [강의 자료 지침](lecture-prose.md)의 L1-13을 따르며 개별 단어를 일괄 금지하지 않습니다.

## 발표자료 보완: L1-14·L1-15

- **L1-14:** `A보다 B에 가깝다`가 정의·판단을 대신하는 반복 문형인지 확인합니다. 비교의 종류·정도·유보를 보존하며 `B다`로 자동 단정하지 않습니다.
- **L1-15:** 서로 독립적인 세 항목·실제 세 단계와 형식을 채운 3항 나열을 구분합니다. 항목 수와 고유한 정보를 임의로 바꾸지 않습니다.

[발표자료 8유형 지침](presentation-prose.md)에서 판정·예외를 확인합니다. L1-3·L1-8의 추상 명사구, L1-6의 중요성·명료함 선언, L1-11의 선행 대상 없는 지시어, L1-13의 목적 없는 ‘함께 보기’도 이 지침을 함께 참고합니다.

## L1-16. 메타카피: 글에 대한 예고·자평

내용 대신 글·절·슬라이드가 무엇을 다룰지 예고하거나 글의 전달 방식을 스스로 평가하는 문장입니다. 지워도 정보가 줄지 않으면 줄입니다. 목차 안내·범위 한정처럼 독자의 읽기를 돕는 장치(메타담화)는 정상 용법이며, 이 항목은 그 장치가 내용을 대신할 때만 다룹니다. 앞 내용을 되풀이하는 결산·훈계는 L1-6, 글 자체를 가리키는 예고·자평·맺음말은 위치와 관계없이 L1-16으로 봅니다.

| 패턴 | 교정 | 남기는 경우 |
|---|---|---|
| `본 절에서는 ~을 살펴보고자 한다`, `지금부터 ~을 살펴보겠습니다` 뒤에 같은 내용 | 예고를 지우고 내용 문장으로 시작. 슬라이드는 내용이 드러나는 제목 | 다른 위치를 안내하는 문장(`실험 조건은 3장에 설명한다`, `2장은 데이터셋, 3장은 실험`) |
| `결론부터 말씀드리면`, `한마디로 정리하면` | 결론을 바로 씀 | 요약임을 밝혀야 하는 초록·요약 절 |
| `한눈에 조망`, `체계적으로 정리했습니다`, `이해를 돕기 위해 간결하게 정리했습니다` | 삭제. 글의 전달 방식은 독자가 판단 | 편집 결과 보고에서 실제로 바꾼 내용(`표 2의 단위를 ms로 통일했습니다`) |
| 제목 `주요 인사이트`, `핵심 요약`, `시사점` | 본문에서 확인되는 주장·대상으로 바꿈 | 문서 양식이 정한 절 이름, 실제 요약·시사점을 담아 독자가 절을 찾는 데 쓰는 제목 |
| `도움이 되었기를 바랍니다` 같은 대화형 맺음말 | 문서 본문이면 삭제 | 실제 편지·이메일의 인사 |

- 다루는 범위를 정하거나 다른 문서로 보내는 문장(`이 문서는 v2 마이그레이션만 다룹니다. 설치는 INSTALL.md를 참고하십시오`)은 유지합니다. 강의·발표의 실제 진행 안내(`10분 실습 후 질문을 받겠습니다`)도 유지합니다.
- 예고를 더 짧은 예고로 바꾸는 것만으로는 교정이 끝나지 않습니다. `본 절은 ~을 한눈에 조망합니다`를 `이 절에서는 ~을 정리합니다`로 줄였다면 뒤의 내용으로 시작할 수 있는지 다시 봅니다.
- 예고 뒤에 실제 내용이 없으면 내용을 지어내지 않습니다. 제목을 결과 주장으로 바꿀 때도 본문에 있는 수치·결론만 씁니다. 가리키는 정보가 다른 절·표에도 없으면 원문을 유지하고 확인 사항을 적습니다.
- `꼼꼼히 검토했습니다`처럼 글이 아니라 작업의 품질을 보증하는 문장은 L3-10에서 봅니다.
