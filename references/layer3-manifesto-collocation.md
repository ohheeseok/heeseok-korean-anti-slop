# Layer 3. 초압축 선언문과 연어(Collocation) 복원

지침, 원칙, 체크리스트, 연구 노트를 쓸 때 LLM이 자주 만드는 "십계명식 현재형 선언문"과
과압축 명사구를 고칩니다. 원어민 연구자·엔지니어가 실제로 쓰는 문장 구조와 서술어–목적어
호응을 따르십시오.

## L3-1. 선언형 현재형 종결의 반복

모든 항목을 비인칭 현재형 평서문(`~한다`, `~하지 않는다`)으로 끝내면서 대상·조건까지 생략하면 번역된 선언문처럼 보일 수 있습니다. 이 스킬에서는 이런 표현 방식을 초압축 메니페스토 슬롭(Hyper-Compressed Manifesto Slop) 또는 원칙주의적 의사 엄밀성(Performative Epistemic Rigor)으로 설명합니다. 명칭의 범위는 [문체 안내](style-patterns.md)를 참고하십시오.

문서 종류가 없는 단문·발췌문은 원문의 우세한 어미를 유지합니다. 아래 예시는 원문의 `~다`체를 유지합니다. 문장에 문제가 없으면 그대로 두며, 특정 문서가 다른 어미를 요구할 때만 조정합니다.

`~한다`나 `~하지 않는다` 자체가 문법 오류라는 뜻은 아닙니다. 작성자가 피하고 싶은 선언문 반복과 조건 생략을 문서의 종류에 맞게 고칩니다.

- 문제 예: `성공을 전제하지 않는다.` `오판 비용을 기록한다.` `연구 부재를 단정하지 않는다.`
- 교정: 먼저 원문의 서법을 보존한 뒤 문서 위계에 맞춰 통일합니다(`register-guide.md`).
  - 설명 문단 → 원문 말투를 유지합니다. 보고서가 명시적으로 `~합니다`체를 요구할 때만 바꾸며 이유를 새로 붙이지 않습니다.
  - 원문의 명령·지시 → `~하십시오`
  - 원문의 의무·요건 → `~해야 합니다`
  - 설명·평서 → 평서형 유지. 어미 변경으로 명령·의무를 만들지 않습니다.
  - 표 칸·체크리스트 → 개조식 명사형(`~ 기록`, `~ 사전 확정`)

| 전 | 후 |
|---|---|
| 7–8B는 적재 가능성을 확인한 뒤 시도하며 성공을 전제하지 않는다. | 7–8B는 적재 가능한지 확인한 뒤 시도하며 성공할 것이라고 가정하지 않는다. |
| CE 사용 여부로 이산·연속을 판정하지 않는다. | CE 사용 여부로 이산과 연속을 판정하지 않는다. |
| 평가기와 보상기를 분리한다. | 평가기와 보상기를 분리한다. |

## L3-2. 서술어–목적어 호응 오류(영어 직역 연어)

영어 동사를 사전적 의미로 옮겨 한국어 목적어와 어울리지 않는 조합을 고칩니다.

| 검토 표현 | 설명용 영어 대응(원문 확인 아님) | 한국어 교정 후보 |
|---|---|---|
| 효과를 절제한다 | temper the effect | 의미 확인 후 선택: 효과를 과대평가하지 않는다 / 요인별 효과를 구분한다 / 영향을 제한한다 등. 목록은 해석의 근거가 아니며 실험 방법은 추가하지 않음 |
| 비용을 센다 | count the cost | 문맥에 따라 비용을 계산한다·집계한다·산정한다·측정한다. 실제 집계·추정·측정 중 무엇인지 임의로 정하지 않음 |
| 질문으로 적는다 | write as a question | 질문 형태로 적는다. 가설 수립으로 의미를 바꾸지 않음 |
| 가정을 남긴다 | leave assumptions | 가정을 명시한다 |
| 결론을 내린다고 읽는다 | read as concluding | 결론으로 해석한다 |
| 신호를 되먹인다 | feed back the signal | 신호를 다시 사용한다 |
| 예산을 태운다 | burn the budget | 예산을 사용한다, 소진한다 |
| 실험을 돌린다(공식 문서) | run experiments | 실험을 수행한다, 실행한다 |

## L3-3. 과압축 명사구 풀어쓰기

조사 `의`나 가운뎃점(`·`)으로 행위·사건 명사 3개 이상을 한 덩어리로 묶지 마십시오. 원문 문맥에서 확인되는
주어와 조건절만 복원해 언제, 무엇을 했을 때의 결과인지 드러나게 씁니다.

| 전 | 후 |
|---|---|
| 조기 종료·재샘플링의 오판 비용을 기록한다. | 조기 종료·재샘플링과 관련된 오판으로 발생한 비용을 기록한다. |
| 계획 수정과 단순 검증 선택의 효과를 절제한다. | 계획 수정과 단순 검증 선택의 효과를 절제한다. |
| 병렬 확정의 의존성 오차 | 병렬로 확정할 때 발생하는 의존성 오차 |
| 이해 감독의 생성 이득 | 원문 유지 |

위 표의 `이해 감독의 생성 이득`은 지칭 대상이 없으면 전문 용어를 임의로 풀지 않는 예입니다. `효과를 절제한다`도 의미가 불분명하여 원문을 유지한 항목입니다. 확인 메모는 본문 밖에 적습니다: 과대평가 금지·효과 구분·영향 제한 등 어느 뜻이며 무엇을 선택한다는 뜻인지 확인 필요.

교정문 뒤에 원문에 없던 확인 절차를 붙이지 않습니다. 비용의 정의나 분리 방식이 문맥에 없고 교정에 필요할 때만 본문 밖의 `확인 필요`에 적습니다.

목록으로 나열된 개체 이름(`VAE·VQ·FSQ`, `IFEval·GSM8K·HumanEval`)은 행위 명사가 아니므로
그대로 둡니다.

## L3-4. 번역투 간접의문문

영어 `decide what to X and which Y to Z`를 옮긴 이중 의문사절을 구체 명사구로 바꿉니다.

| 전 | 후 |
|---|---|
| 무엇을 고정하고 어떤 비용을 셀지 정한다. | 고정할 항목과 계산할 비용을 정한다. |
| 무엇을 조건부 단위로 삼는지 ③에 적는다. | 조건부 단위는 ③에 기록한다. |
| 세 선택을 조합할 수 있는지와 실제 성능은 따로 검증한다. | 세 선택의 조합 가능성과 실제 성능은 각각 검증한다. |
| PEFT·RL로 넘어갈지 이 결과로 판단한다. | PEFT·RL 단계 진행 여부를 이 결과로 판단한다 |

위 비용 예시는 비용값을 구한다는 뜻이 문맥상 확인된 경우입니다. 비용의 포함 범위를 정하는 뜻이면 그 관계를 유지하며, 단순한 개수 세기·산정·측정 중 하나를 임의로 선택하지 않습니다.

의문절이 하나뿐인 자연스러운 호응(`보상이 올랐는지 확인`, `효과가 유지되는지 검증`)은
남깁니다.

## L3-5. 개조식 표 칸 작성법

- 문장부호로 끝내지 않거나 마침표를 일관되게 씁니다.
- 명사형 종결은 `~ 기록`, `~ 측정`, `~ 확보`, `~ 기각`, `~ 필요`, `~ 가능`, `~ 아님`처럼 행위나 상태가 드러나게 씁니다.
- 명사형으로 작성하는 표라면 `~하지 않는다.`를 `~하지 않음`으로 옮길 수 있습니다. `~ 불가`는 불가능·불허, `~ 금지`는 금지 의미가 원문에 있을 때만 씁니다. 이유·조건도 원문에 있을 때만 덧붙입니다.
- 같은 기능을 하는 칸의 형식은 맞출 수 있습니다. 다만 명령·의무·관찰·가설 등 기능이 다르면 종결 방식도 다를 수 있으며 어미 통일보다 의미를 우선합니다.

## L3-6. 서법 보존

- 당위(`~해야 한다`)를 사실(`~한다`)로, 추측(`~일 수 있다`)을 단정으로 바꾸지 않습니다.
- 가설은 원문의 추정 강도와 말투를 유지합니다. 가능성을 예상으로, 예상을 사실로 바꾸지 않습니다.
- 반증 조건의 조건절·판정 내용을 보존합니다. 표가 명사형을 사용한다면 `~이면 가설 기각`처럼 쓸 수 있지만 문장형을 일괄 변환하지 않습니다.

## L3-7. 강의 자료의 교훈형 판정과 실제 조건

`사고가 나도 되는 상태`, `되돌리지 않으면 성공이 아니다` 같은 표현을 다듬을 때 실제 조치·완료 조건은 남깁니다. `~합니다`로 어미를 바꾸는 것만으로 해결되지 않습니다. [강의 자료 지침](lecture-prose.md)의 L3-7을 참고합니다.

## 기술 해설에서 함께 볼 표현

한 문장 요약의 `A하지 말고 B하십시오`는 문법이나 지시형 어미 자체보다 두 방법의 관계를 먼저 확인합니다(L1-5·L1-12). `한 모드에 커밋`, `우아하게 반응`의 전문적인 의미·평가 강도는 [기술 해설 지침](technical-explanation.md)의 L3-2 보완을 따릅니다. 명령형 요약을 평서문으로 바꾸는 것만으로 설명 누락이 해결되지는 않습니다.
