# 여러 절에 걸친 문체를 검토할 때

긴 자료는 한 절만 읽으면 정상인 표현이 여러 절에서 같은 설명을 대신할 수 있습니다. 반대로 제목·정의·결론에서 필요한 용어와 주장을 반복하기도 합니다. 두 경우를 문서 전체의 기능으로 구분합니다. 짧은 문서에 분할 절차를 억지로 적용하지 않습니다.

## 먼저 전체 문맥을 확인

제목·목차·요약과 절별 주제를 읽고 실제 용어 정의, 비교 범위, 지칭 대상, 인용 구간을 파악합니다. ‘손·자리·층’이 앞에서 정의된 별칭인지, 요약의 ‘세 가지’가 실제 어느 세 항목인지 확인합니다. 이 정보는 내부 검토에 쓰면 되고 매번 별도 표를 출력할 필요는 없습니다.

## 필요한 만큼 나눠 읽기

- 절·슬라이드·문단의 경계를 우선합니다. 고정 글자 수에 맞추려고 수식·목록·표·인용이나 문장 중간을 자르지 않습니다.
- ‘그 기준’, ‘이 결과’, ‘앞의 두 항목’ 같은 표현의 선행 대상이 다른 절에 있으면 그 문맥을 함께 읽습니다. 관계가 확인되지 않았다는 이유로 새로운 기준을 만들어 넣지 않습니다.
- 나눠 교정한 부분을 합칠 때 용어·말투·번호·조건과 문장 연결이 유지되는지 대조합니다. 같은 대상을 다른 동의어로 바꾸거나 평서를 의무로 바꾸지 않습니다.
- 읽지 못한 부분이나 추출되지 않은 그림·동적 문구가 있으면 그 범위만 밝힙니다. 일부 발췌를 보고 문서 전체를 점검했다고 하지 않습니다.

## 합친 뒤 문서 전체에서 다시 볼 것

| 검토 대상 | 실제로 묻는 질문 |
|---|---|
| 반복되는 병목 진단 | 각 절이 다른 제한 원인을 설명하는가, 같은 진단 틀이 그 설명을 대신하는가? |
| 경구형 도입·맺음말 | 앞의 사실을 꾸며 되풀이하는가, 새 조건·평가·다음 행동을 전달하는가? |
| 3항 나열 | 절마다 세 항목에 맞춘 추상어인가, 실제 독립 항목·순서가 있는가? |
| 동일 명사·어미 | 같은 개념·문서 기능을 유지하는 필요한 반복인가, 내용 없는 틀의 반복인가? |
| 요약과 본문 | 조건·예외·추가 설계·범위가 요약에서도 유지되는가? |
| 절 사이의 연결 | 나란히 있던 사례를 새 인과나 목적 관계로 합치지 않았는가? |

횟수는 위치를 찾는 단서입니다. 일정 횟수를 넘으면 자동으로 지우거나 다른 문형으로 돌려 쓰지 않습니다.

## 반복을 줄여도 제약은 남기는 예

다음은 합성 예시입니다.

| 절 | 원문 | 교정 예시 |
|---|---|---|
| 파일 준비 | 형식이 병목입니다. 두 파일의 날짜 형식이 달라 결합 작업이 중단됩니다. | 두 파일의 날짜 형식이 달라 결합 작업이 중단됩니다. |
| 승인 | 절차가 병목입니다. 승인 요청을 매주 한 번 처리해 후속 작업이 늦어집니다. | 승인 요청을 매주 한 번 처리해 후속 작업이 늦어집니다. |

제약 설명이 이미 있으므로 진단 문장만 줄일 수 있습니다. 두 원인과 주기·결과를 합치거나 하나가 다른 하나의 원인이라고 쓰지 않습니다. 원인이나 제한 대상이 없으면 제약 설명을 새로 쓰는 대신 필요한 확인 사항을 남깁니다.

제목이 승인 대기를 주제로 삼고 본문이 실제 처리량을 측정한 뒤 결론이 같은 시험 범위의 제약을 재확인한다면, 그 반복은 논지 구성에 필요할 수 있습니다. ‘병목’이 두 번 나온다는 이유로 두 곳 모두 지우거나 ‘영향을 줄 수 있다’로 약화하지 않습니다.
