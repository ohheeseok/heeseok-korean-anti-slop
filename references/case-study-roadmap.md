# 사례: 생성모델 통합 연구 로드맵(2026-10)

이미지 생성, diffusion/flow 언어모델, 이해·생성 통합 모델을 다룬 한국어 HTML 로드맵을 세
단계에 걸쳐 교정한 실제 기록입니다. 첫 단계는 im-not-ai 기준(연결어미 쉼표, 결산어), 둘째
단계는 L2(은유·경구), 셋째 단계는 L3(선언문·연어)였습니다. 사용자가 단계마다 지적한 문장을
그대로 실었습니다. 이 문서는 과거 사례를 바탕으로 정리한 편집 자료이며 원문 전체가 동봉되어 있지 않습니다. 제목의 수치·모델 세부사항처럼 주변 문맥에 의존하는 교정은 해당 문맥을 확인한 경우에만 적용합니다. 1.0.2에서 의미를 추가하던 일부 교정안을 수정했습니다.

## 1. 제목(L2)

| 원문 | 교정 | 규칙 |
|---|---|---|
| 생성모델, 여섯 칸으로 읽다 | 생성모델 통합 연구 로드맵 | L2-1, L2-6 |
| 읽는 법 | 기록 방법 | L2-6 |
| 공통 좌표계와 분류 원칙 | 여섯 설계 항목과 분류 원칙 | L2-2 |
| 네 식을 연결하고 가정을 남긴다 | 대표 수식 네 개와 적용 조건 | L2-1, L3-2 |
| 토큰의 정체성 가리기 | 토큰을 [MASK]로 바꾸는 손상 | L2-5 |
| 패러다임과 모달리티를 교차해 읽는다 | 생성 방식 × 모달리티 분류표 | L2-1, L2-6 |
| 선정 문헌의 병존 | 선정 문헌의 첫 공개 연도 | L2-5 |
| 선수지식 하나, 학습 모듈 일곱 | 선수지식 1개와 학습 모듈 7개 | L2-3 |

도식 글자, `aria-label`까지 한 번에 교체했습니다.

## 2. 본문 은유와 의인화(L2)

| 원문 | 교정 | 규칙 |
|---|---|---|
| 그 차이를 재현 가능한 연구 질문으로 좁힌다. | 모델 간 차이를 재현 가능한 연구 질문으로 정리합니다. | L2-1 |
| 조건과 모달을 어디서 묶나 | 조건과 모달의 결합 위치 | L2-1 |
| 평가는 데이터와 함께 모든 칸을 관통한다. | 평가는 모든 항목에 공통 적용 | L2-1 |
| 평가는 데이터·학습·샘플·비용을 가로질러 측정한다. 일부 신호는 ⑥ 보상·사후학습으로 되먹이지만 | 평가는 데이터, 학습, 샘플, 비용 전체를 대상으로 합니다. 평가 신호 일부를 ⑥의 보상이나 사후학습에 다시 쓰더라도 | L2-1 |
| 단일 velocity MSE로 축약하면 이 설계를 놓친다. | 이 손실을 단일 velocity MSE로 요약하면 두 CE 항이 빠지게 됩니다. | L2-5 |
| 이 순서로 읽으면 9–12주 실험의 비교 기준이 갖춰진다. | 네 편은 각각 편집 궤적, 계산 배분, 품질 분포, 편집 보상을 다룹니다. 9–12주 실험에서 비교 기준으로 씁니다. | L2-5 |
| 레인은 이 문서의 독해용 분류이며 서로 다른 계열의 병존을 보여준다. | 레인은 이 문서에서 정한 분류이며 서로 다른 계열의 문헌이 같은 시기에 발표됐다는 사실만 나타냅니다. | L2-5 |
| 세 논쟁은 서로 다른 축이다. | 자주 논쟁되는 세 가지 구분은 서로 다른 설계 항목에 속합니다. | L2-4 |
| 학습 데이터와 예산까지 통제한 계열 간 인과 비교로 읽지 않는다. | 학습 데이터와 예산까지 통제한 인과 비교는 아님 | L2-6, L3-5 |
| (도식) 학습 때만 지나는 길 / 모든 칸을 가로지르는 채널 | 학습할 때만 사용 / 모든 항목에 적용 | L2-7 |

## 3. 선언문·연어·명사구(L3)

사용자가 지적한 다섯 문장입니다.

| 원문 | 교정 | 규칙 |
|---|---|---|
| 성공을 전제하지 않는다. | 성공할 것이라고 가정하지 않습니다. | L3-1 |
| 연구 부재를 단정하지 않고 비교 조건과 반증 가능한 질문으로 적는다. | 관련 연구가 없다고 단정하지 않습니다. 비교 조건과 반증 가능한 질문을 적습니다. 무엇에 관한 조건과 질문인지는 문맥에서 확인합니다. | L3-1, L3-2 |
| 조기 종료·재샘플링의 오판 비용을 기록한다. | 조기 종료나 재샘플링 과정에서 잘못된 판단으로 발생한 비용을 기록합니다. | L3-3 |
| 계획 수정과 단순 검증 선택의 효과를 절제한다. | 원문 유지(의미 확인 필요, 본문 밖에 확인 항목 작성) | L3-2, L3-3 |
| 모델을 실행하기 전에 무엇을 고정하고 어떤 비용을 셀지 정한다. | 실험을 시작하기 전에 고정할 항목과 산정할 비용을 정합니다. | L3-2, L3-4 |

같은 유형으로 함께 고친 예:

| 원문 | 교정 | 규칙 |
|---|---|---|
| 연속 시간과 연속 상태는 다르다. Dream은 연속 시간으로 기술해도 다음 단계에 이산 토큰과 [MASK]를 전달한다. | 연속 시간과 연속 상태는 다른 개념입니다. Dream은 시간을 연속 변수로 정식화하지만 다음 단계로 전달하는 상태는 이산 토큰과 [MASK]입니다. | L3-1 |
| (표 칸) 데이터 종류나 신경망 내부 hidden vector로 분류하지 않는다. 코덱은 ④에 적는다. | 데이터 종류와 신경망 hidden vector는 분류 기준에서 제외. 코덱은 ④에 기록 | L3-5 |
| 병렬 확정의 의존성 오차가 어느 step에서 커지는가? | 여러 토큰을 한 step에 동시에 확정할 때 생기는 의존성 오차는 어느 step에서 커지는가? | L3-3 |
| token·block·scale 등 무엇을 조건부 단위로 삼는지 ③에 적는다. | 조건부 단위는 ③에 기록합니다. | L3-4 |
| (반증) saliency의 추가 이득이 없으면 그 구성요소를 기각한다. | saliency를 추가해도 개선이 없으면 saliency 구성요소 기각 | L3-5, L3-6 |
| (가설) ~하면 동일 총 비용에서 지시 이행과 지각 품질·보존이 개선된다. | ~하면 같은 총비용에서 지시 이행, 지각 품질, 보존 점수가 개선될 것으로 예상합니다. | L3-6 |

| 고정하는 칸을 표시하고, 평가 조건은 별도 줄에 남긴다. | 고정하는 항목을 표시하고 평가 조건은 별도 줄에 기록합니다. | L1-7 |
| Gaussian 조건부 score는 −ε/σ이고, 그 조건부 평균을 예측하면 | Gaussian 조건부 score는 −ε/σ이고 그 조건부 평균을 예측하면 | L1-7 |
| 아래는 검증 전 가설이며 신규성이 확립됐다는 주장이 아니다. 연구가 없다고 단정하는 대신 | 아래 세 가설은 검증 전 제안이며 신규성은 아직 확인하지 않았습니다. | L1-5 |

## 5. 교정 과정에서 얻은 교훈

- 제목, 영문 kicker, 표 머리, 범례, `aria-label`, SVG `<desc>`, 도식 글자, 스크립트 안내문에서 같은 패턴이 반복됐습니다. 본문만 고치면 절반쯤 남습니다.
- 은유를 지우면서 `~한다.` 선언형으로 바꾸면 L3 문제가 새로 생깁니다. 은유 교정과 어미 결정은 함께 해야 합니다.
- 핵심 용어가 은유면 문서 전체에서 한 번에 교체합니다. 일부만 바꾸면 같은 개념이 두 이름으로 남습니다.
- 기계 검사의 `지도` 같은 짧은 키워드는 `속하지도`, `커지는지도`에서 오탐이 납니다. 표시된 문장은 문맥을 보고 판단합니다.
