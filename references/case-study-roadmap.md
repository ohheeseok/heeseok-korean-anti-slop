# 사례 노트: 생성모델 통합 연구 로드맵

제공받은 스킬에 포함돼 있던 로드맵 사례를 1.1.0 점검에서 정리했습니다. 원문 전체는 동봉되어 있지 않습니다. 이 파일은 검증된 정답표가 아니며, 확인할 수 없는 주변 사실을 교정문에 복원하지 않습니다. 기존의 CE 항·문헌 수·실험 주차·모델 설명을 보충한 예시는 제거했습니다.

## 의미를 확인할 수 있는 범위의 예시

| 원문 | 교정 예시 | 보존·확인할 점 | 규칙 |
|---|---|---|---|
| 네 식을 연결하고 가정을 남긴다 | 네 수식의 관계와 가정 | 제목을 명사구로 정리. 가정을 적용 조건으로 바꾸지 않음 | L2-1, L3-2 |
| 선수지식 하나, 학습 모듈 일곱 | 선수지식 1개와 학습 모듈 7개 | 두 분류와 각 개수 보존 | L2-3 |
| 핵심 12주, 확장 12주 | 핵심 과정 12주와 확장 과정 12주 | 두 기간의 순서·겹침이 불명확하므로 24주로 합산하지 않음 | L2-3 |
| 모델 해부표 / LLaDA·Dream·Lafa 한 표 | 모델 비교표 / LLaDA·Dream·Lafa 비교 | 표가 비교 목적임이 확인된 경우. 모델명 보존 | L2-2 |
| 그 차이를 재현 가능한 연구 질문으로 좁힌다 | 그 차이에 관한 재현 가능한 연구 질문으로 범위를 한정한다 | ‘그 차이’의 지칭 대상은 원문에서 확인. 새 모델·실험 대상 추가 금지 | L2-1 |
| 성공을 전제하지 않는다 | 성공할 것이라고 가정하지 않는다 | 서법·어미 유지. 실패 대비 절차를 새로 만들지 않음 | L3-1 |
| 조기 종료·재샘플링의 오판 비용을 기록한다 | 조기 종료·재샘플링과 관련된 오판으로 발생한 비용을 기록한다 | 오판의 구체적 대상·비용 단위를 추가하지 않음 | L3-3 |
| 모델을 실행하기 전에 무엇을 고정하고 어떤 비용을 셀지 정한다 | 모델을 실행하기 전에 고정할 항목과 계산할 비용을 정한다 | 모델 실행 시점을 전체 실험 시작 시점으로 바꾸지 않음 | L3-2, L3-4 |
| token·block·scale 등 무엇을 조건부 단위로 삼는지 ③에 적는다 | token·block·scale 등의 조건부 단위를 ③에 적는다 | 예시 목록과 표의 위치 ③ 보존 | L3-4 |
| 학습 데이터와 예산까지 통제한 계열 간 인과 비교로 읽지 않는다 | 학습 데이터와 예산까지 통제한 계열 간 인과 비교로 해석하지 않는다 | ‘계열 간’ 범위와 부정 보존 | L2-6 |

## 의미가 갈리면 해당 구간만 유지

- `연구 부재를 단정하지 않고 비교 조건과 반증 가능한 질문으로 적는다`: 연구가 없다고 단정하지 않는다는 뜻과 질문으로 쓴다는 뜻은 확인됩니다. 목적어와 비교 조건이 없으면 무엇을 작성하라는 것인지 보충하지 않습니다.
- `계획 수정과 단순 검증 선택의 효과를 절제한다`: ‘절제’의 뜻과 선택 대상이 불명확합니다. 원문을 유지하고 필요한 확인 사항만 본문 밖에 적습니다.
- `토큰의 정체성 가리기`, `필독 최소 경로`, `선정 문헌의 병존`: 실제 손상 방식·문헌 수·공개 연도가 없으면 `[MASK]`, 8편, 연도표 같은 사실을 만들지 않습니다.

## 재사용할 교훈

- 같은 개념을 바꾸면 제목·목차·표 머리·범례·접근성 라벨에서도 이름을 일관되게 씁니다.
- 문장을 다듬으면서 원문 예시 목록·수치·가정·비교 범위를 지우지 않습니다.
- 과거 사례에 더 구체적인 사실이 적혀 있어도 새 문서에 가져오지 않습니다. 실제 사용자의 원문을 판단 근거로 삼습니다.
