# 교정 행동 점검 사례

스킬 수정 후 실제 교정을 평가할 때 사용하는 입력과 보존 기준입니다. 특정 문구와 일치하는지를 점수화하지 않습니다. 교정 전 원문과 결과를 대조해 사실·조건·추정·접속 관계가 유지되는지 확인합니다. 아래 기준은 모델 성능 수치나 자동 합격 판정이 아닙니다.

| 입력 | 기대하는 행동·보존 기준 |
|---|---|
| 이 계획이 성공할 가능성은 아직 확인하지 않았다. 실패할 수 있으므로 성공을 전제하지 않는다. | 가능성이 미확인이라는 상태와 실패 가능성·인과를 보존. 대안 모델이나 추가 준비 절차를 넣지 않음. |
| 조기 종료·재샘플링의 오판 비용을 기록한다. 비용은 추가 GPU 시간으로 정의한다. | 비용의 정의를 그대로 유지하고 압축 명사구만 풀기. 이미 제공된 비용 정의를 다시 묻지 않음. |
| 계획 수정과 단순 검증 선택의 효과를 절제한다. | 의미 확인 전 원문 유지. 효과·선택의 뜻에 필요한 확인만 본문 밖에 적기. |
| 모델을 실행하기 전에 무엇을 고정하고 어떤 비용을 셀지 정한다. | 실행 전이라는 순서, 고정 항목과 비용 결정이라는 두 내용을 보존. 의무·실험 지표를 추가하지 않음. |
| 연구 부재를 단정하지 않고 비교 조건과 반증 가능한 질문으로 적는다. | 연구가 없다는 단정을 피한다는 의미를 보존. ‘선행’ 범위나 대상·실험 절차를 지어내지 않음. 호응을 확정할 수 없으면 확인. |
| API를 통해 자료를 전달한다. 모델의 표현 공간은 3차원 좌표계로 시각화한다. 처리 시간이 18시간에서 11시간으로 줄었을 수 있다. | API 경로·수학적 좌표계·수치·가능성을 유지. 문서 종류 미지정 시 원래 어미 유지. |
| 사람은 하나지만 자리는 두 개입니다. | 자리의 뜻을 임의로 좌석·역할·정원으로 단정하지 않음. 뜻 확인 전 원문 유지. 대비 관계를 단순 나열로 바꾸지 않음. |
| 실제 양식의 6칸을 채운다. 장치의 손잡이를 돌린다. | 문자 그대로의 표현 유지. 변수·항목·파라미터로 바꾸지 않음. |
| 백본 공유가 표현 공유를 보장하지 않는다. | 보장할 수 없다는 뜻을 실제로 공유하지 않는다는 사실 단정으로 바꾸지 않음. |
| CE 사용 여부로 이산·연속을 판정하지 않는다. | ‘만으로’를 임의로 추가해 원문의 기준 배제를 완화하지 않음. |

이 검토에서는 원문 의미에 영향을 주지 않는 자연스러운 지시어·조사·어휘 변경을 허용합니다. 한 글자도 바꾸지 않는 검사가 아닙니다. 확인 질문은 교정에 필요한 의미가 불분명할 때만 적고, 실험 설계·사실 검증으로 범위를 확장하지 않습니다.

검사기의 CLI 회귀 테스트(`tests/test_scan_slop.py`)는 후보 탐지·미탐·오탐과 입력 파일 불변성만 확인합니다. 위 의미 보존 행동을 자동으로 검증하지는 않습니다.

가운뎃점은 목록의 병렬·대안·공동 조건 중 무엇인지 문맥에서 판단합니다. 조기 종료·재샘플링의 오판이 의사결정 오류인지 과정 중 오류인지 불분명하면 그 범위를 좁히지 않습니다.

## 강의·실습 자료 추가 점검

| 입력·문맥 | 기대하는 행동 |
|---|---|
| 손이 없어서 못 한 겁니다. 주어는 챗봇. | 기능·접근 대상·실행 조건 중 무엇을 뜻하는지 원문에서 확인. 권한이 없었다고 추측하지 않음. 비유를 문자 그대로 이해하거나 모든 챗봇의 능력으로 일반화하지 않음. |
| 앱 안의 다른 자리 / 1층에서 부탁 / 3층으로 옮겨 폴더 지정 | 원문에 있는 기능명·화면명과 대응시켜 설명. 앞 차시에 정의했을 가능성을 고려하고 물리적 층수·실제 좌석·전문 계층 용어와 구분. |
| 같은 프롬프트가 대화 시연과 실행 시연에 반복됨 | 입력 동일성이 비교 조건이면 글자까지 보존. 반복 문구라는 이유로 삭제·윤문하지 않음. |
| 같은 요청 뒤 파일 이름이 바뀌고 ‘바뀐 건 자리’라고 결론 | 요청·실행 경로·폴더 지정 등 관찰된 조건을 구분. 단일 원인이나 제품 전체의 능력을 새로 단정하지 않음. |
| 되돌려 보지 않았다면 아직 성공이 아닙니다. 완료 조건으로 제시됨 | ‘되돌리기 확인 전에는 미완료’라는 조건 보존. 선택적인 권고로 약화하거나 원문에 없는 안전·성공 조건 추가 금지. |
| 복사본으로 작업합니다. / 이런 폴더, 있으시죠 / 직접 해보겠습니다 | 실제 절차, 학생에게 하는 질문, 강사의 시연 예고라는 역할이 분명하면 유지. 구어체나 짧은 어미 자체를 슬롭으로 판정하지 않음. |

검토자가 제공받지 못한 앞선 차시·제품의 현재 기능·실제 권한 설정은 확인한 것처럼 쓰지 않습니다. 스킬 개선만 요청받았으면 입력 자료에 쓰지 않고 원문에서 추출한 판단 기준만 개선합니다.
