# Layer 2. 은유·경구(가짜 문학성) 제거

추상적인 개념, 설정 변경, 진행 과정을 물리적 사물이나 도구를 다루는 행위로 바꿔 말한 문장을
고칩니다. 인위적인 대구와 정의로 통찰이 있는 것처럼 꾸민 문장도 같이 고칩니다. 장식적 비유를 줄이고 사실과 논리를 직접 전달하도록 씁니다. 실제 사물·양식·수학적 좌표계를 뜻하는 표현은 유지합니다. 아래 치환은 원문에서 지칭 대상을 확인할 수 있을 때만 적용합니다. 지칭 대상과 행동이 이미 명시된 부분은 고치며, 예외를 이유로 문서 전체를 원문 유지로 끝내지 않습니다.

## L2-1. 물리·촉각 조작 은유 동사

추상적인 작업을 물건을 다루는 동작으로 표현한 동사를 지우고 실제 작업을 씁니다.

| 은유 | 실제 작업으로 |
|---|---|
| 빈칸(6칸)을 채운다 | 6개 항목을 작성한다 / 기록한다 |
| 손잡이·다이얼을 돌린다, 스위치를 켠다, 기어를 바꾼다 | 파라미터 X를 수정한다, 옵션 Y를 활성화한다 |
| 영점을 조절한다, 해상도를 높인다 | 기준값을 다시 정한다, 세부 기준을 구체화한다 |
| 퍼즐 조각을 맞춘다, 단추를 끼운다 | 구성 요소를 연결한다, 첫 단계를 진행한다 |
| 연구 질문으로 좁힌다 | 연구 질문으로 범위를 한정한다. 범위 축소 의미 보존 |
| 조건과 모달을 어디서 묶나 | 조건과 모달의 결합 위치 |
| 모든 칸을 관통한다 | 모든 항목에 적용된다 |
| 데이터·비용을 가로질러 측정한다 | 측정 범위·조건을 원문에서 확인해 직접 설명. ‘전체’로 범위를 확대하지 않음 |
| 보상으로 되먹인다 | 보상에 다시 사용한다 |
| loss routing을 따라간다 | loss routing을 확인한다 |
| 관심과 맞닿는 단계 | 관심과 관련된 단계 |
| 렌즈를 바꾼다 | 분석 기준을 바꾼다 |

## L2-2. 도구·장소·신체 명사 은유

개념 체계나 문서 구성을 지도, 해부, 건축물, 신체로 부르는 명사를 고칩니다. 제목과 영문
kicker에 특히 많습니다.

| 은유 명사 | 교정 예 |
|---|---|
| 지도, 한 장 지도, atlas | 분류표, 비교표 |
| 해부표, 해부 | 비교표, 구조 분석 |
| 좌표계, 좌표 | 설계 항목, 항목 값 |
| 관문, 게이트 | 완료 기준, 점검 시점 |
| 골격, 뼈대 | 목차, 구조 |
| 프런티어 | 열린 질문 |
| 다리(BRIDGES), 연결 | 대표 수식, 대응 관계 |
| 경로·여정(로드맵 단계의 비유일 때) | 과정, 순서, 단계 |
| 청사진, 엔진, DNA, 나침반, 초석, 심장 | 계획, 핵심 구성 요소, 기준 등 실제 지칭 대상 |

기술 용어로 굳은 표현은 남깁니다: 지도 학습, 기하학적 좌표·좌표계, 확률 경로, 정보 흐름(attention), 파이프라인, 백본, 레이어,
증류, 병목(정확한 기술 의미일 때). 병목을 기술 용어로 남기더라도 진단형 결말의 상투적 반복은 L1-12에서 따로 검토합니다.

## L2-3. 역설적 대구와 경구형 단문

숫자, 크기, 상태를 인위적으로 대비시켜 깊이가 있어 보이게 만드는 단문을 고칩니다.

- 검토 예: `사람은 하나지만 자리는 두 개입니다`, `도구는 가벼워졌지만 책임은 무거워졌습니다`, `질문은 단순하나 답은 복잡합니다`, `속도가 아니라 방향입니다`
- 제목 예: `선수지식 하나, 학습 모듈 일곱` → `선수지식 1개와 학습 모듈 7개`, `핵심 12주, 확장 12주` → `핵심 과정 12주와 확장 과정 12주`
- 교정: 대구가 가리키는 사실을 문맥에서 확인해 직접 씁니다. `사람은 하나지만 자리는 두 개입니다`만으로는 자리가 좌석·직책·역할 중 무엇인지 알 수 없으므로 해당 의미를 확인할 때까지 원문을 유지합니다. 담당자·역할·동시성을 추가하지 않습니다. 실제 수량 차이를 설명하는 문장이라면 대구 형식만으로 바꾸지 않습니다.

## L2-4. 현학적 정의와 은유 등식

문단 첫머리나 끝에서 추상명사로 개념을 다시 정의하는 문장을 고칩니다.

- 검토 예: `결국 아키텍처란 타협의 예술입니다`, `진짜 경쟁력은 속도가 아니라 밀도에서 나옵니다`, `X는 Z의 시그니처다`
- 제목 예: `RePlaid의 배수는 학습 계산량이다` → `RePlaid의 학습 계산량 배수`. FLOPs 등 원문에서 확인하지 못한 단위·지표는 추가하지 않습니다.
- 교정: 판단 근거와 데이터를 씁니다. 등식이 아무 정보도 담고 있지 않으면 문장을 지웁니다.
- 남기는 경우: 실제 정의·사실 등식, 인용으로 보존해야 하는 설명, 필요한 기제를 구체적으로 설명하는 비유. 널리 쓰인 비유라는 이유만으로 무조건 남기거나 지우지 않습니다.

## L2-5. 행위주 호응과 의인화

실제 주어와 동작의 관계를 확인합니다. `이 설계를 놓친다`에서 설계는 목적어이고, `기준이 갖춰진다`는 상태 변화이므로 두 표현을 무생물 주어의 의인화로 자동 분류하지 않습니다.

- `데이터가 말한다`처럼 비유적 동작으로 구체 내용을 대신할 때는 원문에서 확인되는 주장·관측을 직접 씁니다. 데이터가 무엇을 뒷받침하는지 모르면 그 구간만 확인 사항으로 남깁니다.
- `본 연구는 보인다`, `표가 보여준다`, 소프트웨어가 수행하는 동작, 자연 현상과 관계 동사(`포함한다`, `보장하지 않는다`)는 자연스러운 기술 표현일 수 있습니다.
- `백본 공유가 표현 공유를 보장하지 않는다`의 부정을 `표현을 공유하지 않는다`라는 사실이나 `보장할 수 없다`라는 불가능으로 바꾸지 않습니다. 어순을 다듬는다면 `백본을 공유해도 표현 공유가 보장되지는 않는다`처럼 뜻을 유지합니다.
- 주어·행위자·빠진 구성 요소를 새로 만들지 않습니다. CE 항, 문헌 수, 실험 주차 등은 주변 원문에 있을 때만 쓸 수 있습니다.

## L2-6. 해석을 뜻하는 `읽는다`

`~로 읽는다`, `~로 읽지 않는다`가 문서를 읽는 행위가 아니라 해석·분류를 뜻하면 고칩니다.

- `인과 비교로 읽지 않는다` → `인과 비교로 해석하지 않는다`
- `순서 분해로 읽는다` → `순서 분해로 해석한다`
- `세 모델을 같은 질문으로 읽는다`: 질문이 실제 비교 기준인지 문맥에서 확인합니다. 근거 없이 질문을 기준으로 치환하지 않습니다.

논문을 실제로 읽는다는 뜻(`읽기: DDPM → Score SDE`)은 남깁니다.

## L2-7. 의인화된 도식·차트 문구

도식과 차트 안의 짧은 문구도 같은 규칙을 적용합니다. 아래 손상 방식·번호 등은 로드맵 문맥이 확인될 때만 쓰는 예시입니다. 단독 문장만으로 세부 대상을 복원하지 않습니다.

- `학습 때만 지나는 길` → `학습할 때만 사용`
- `모든 칸을 가로지르는 채널` → `모든 항목에 적용`
- `분기는 손상 한 곳에서만 생기지 않는다` → `연속·이산 구분은 ② 손상 방식만으로 정해지지 않음`

## L2-8. 교육용 신체·공간 은유

`손이 없어서`, `앱 안의 다른 자리`, `1층에서 부탁`처럼 기능·조작명을 대신하는 비유는 [강의 자료 지침](lecture-prose.md)의 L2-8을 참고합니다. 실제 사물·전문적인 계층 구조·이미 정의된 별칭은 문맥을 확인하며, 비유를 제거하면서 접근 권한·제품 기능을 추측하지 않습니다.

## L2-9. 기술 용어의 캐릭터화·서사화

`호라이즌 3형제`, `분포가 살아남는다`, `정책에 모델을 심는다`처럼 기술 설명에 친족·생존·물리 동작을 덧대는 표현은 [기술 해설 지침](technical-explanation.md)의 L2-9를 참고합니다. 에너지 지형·기울기장·액션 공간 등 실제 기술 용어와 로봇의 손잡이 조작은 구분합니다. L2-4의 정의형 등식도 실제 수학적 동치인지 설명용 해석인지 확인하며 수식은 보존합니다.

## L2-10. 감각적으로 꾸민 추상어

`정서의 결`, `여운의 농도`, `맥락의 밀도`가 실제 대상·행위를 대신하는지 검토합니다. 다른 추상어로만 바꾸거나 지표·성과를 새로 만들지 않습니다. 물질의 농도·밀도와 재료의 결 등 문자 그대로의 뜻은 보존합니다. [발표자료 지침](presentation-prose.md)의 L2-10을 참고합니다.
