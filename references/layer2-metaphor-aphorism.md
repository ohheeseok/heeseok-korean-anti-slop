# Layer 2. 은유·경구(가짜 문학성) 제거

추상적인 개념, 설정 변경, 진행 과정을 물리적 사물이나 도구를 다루는 행위로 바꿔 말한 문장을
고칩니다. 인위적인 대구와 정의로 통찰이 있는 것처럼 꾸민 문장도 같이 고칩니다. 모든 문장은 비유 없이
사실과 논리를 전달하도록 씁니다.

## L2-1. 물리·촉각 조작 은유 동사

추상적인 작업을 물건을 다루는 동작으로 표현한 동사를 지우고 실제 작업을 씁니다.

| 은유 | 실제 작업으로 |
|---|---|
| 빈칸(6칸)을 채운다 | 6개 항목을 작성한다 / 기록한다 |
| 손잡이·다이얼을 돌린다, 스위치를 켠다, 기어를 바꾼다 | 파라미터 X를 수정한다, 옵션 Y를 활성화한다 |
| 영점을 조절한다, 해상도를 높인다 | 기준값을 다시 정한다, 세부 기준을 구체화한다 |
| 퍼즐 조각을 맞춘다, 단추를 끼운다 | 구성 요소를 연결한다, 첫 단계를 진행한다 |
| 연구 질문으로 좁힌다 | 연구 질문으로 정리한다 |
| 조건과 모달을 어디서 묶나 | 조건과 모달의 결합 위치 |
| 모든 칸을 관통한다 | 모든 항목에 적용된다 |
| 데이터·비용을 가로질러 측정한다 | 데이터·비용 전체에 대해 측정한다 |
| 보상으로 되먹인다 | 보상에 다시 사용한다 |
| loss routing을 따라간다 | loss routing을 확인한다 |
| 관심과 맞닿는 단계 | 관심과 관련된 단계 |
| 렌즈를 바꾼다 | 분석 기준을 바꾼다 |

## L2-2. 도구·장소·신체 명사 은유

개념 체계나 문서 구성을 지도, 해부, 건축물, 신체로 부르는 명사를 고칩니다. 제목과 영문
kicker에 특히 많습니다.

| 은유 명사 | 교정 예 |
|---|---|
| 지도, 한 장 지도, atlas | 분류표, 비교표 |
| 해부표, 해부 | 비교표, 구조 분석 |
| 좌표계, 좌표 | 설계 항목, 항목 값 |
| 관문, 게이트 | 완료 기준, 점검 시점 |
| 골격, 뼈대 | 목차, 구조 |
| 프런티어 | 열린 질문 |
| 다리(BRIDGES), 연결 | 대표 수식, 대응 관계 |
| 경로·여정(로드맵 단계의 비유일 때) | 과정, 순서, 단계 |
| 청사진, 엔진, DNA, 나침반, 초석, 심장 | 계획, 핵심 구성 요소, 기준 등 실제 지칭 대상 |

기술 용어로 굳은 표현은 남깁니다: 확률 경로, 정보 흐름(attention), 파이프라인, 백본, 레이어,
증류, 병목(정확한 기술 의미일 때).

## L2-3. 역설적 대구와 경구형 단문

숫자, 크기, 상태를 인위적으로 대비시켜 깊이가 있어 보이게 만드는 단문을 고칩니다.

- 금지 예: `사람은 하나지만 자리는 두 개입니다`, `도구는 가벼워졌지만 책임은 무거워졌습니다`, `질문은 단순하나 답은 복잡합니다`, `속도가 아니라 방향입니다`
- 제목 예: `선수지식 하나, 학습 모듈 일곱` → `연구 영역 A–H`, `핵심 12주, 확장 12주` → `24주 학습·연구 로드맵`
- 교정: 대구를 풀어 왜 그런 상황인지, 구체 현황이 무엇인지를 씁니다(`담당자 한 명이 두 가지 역할을 동시에 수행합니다`).

## L2-4. 현학적 정의와 은유 등식

문단 첫머리나 끝에서 추상명사로 개념을 다시 정의하는 문장을 고칩니다.

- 금지 예: `결국 아키텍처란 타협의 예술입니다`, `진짜 경쟁력은 속도가 아니라 밀도에서 나옵니다`, `X는 Z의 시그니처다`
- 제목 예: `RePlaid의 배수는 학습 계산량이다` → `RePlaid의 학습 FLOPs 배수`
- 교정: 판단 근거와 데이터를 씁니다. 등식이 아무 정보도 담고 있지 않으면 문장을 지웁니다.
- 남기는 경우: 교과서적 정의(`미토콘드리아는 세포의 발전소`), 사실 등식, 바로 뒤에 메커니즘·수치가 이어지는 비유

## L2-5. 무생물 행위주(의인화)

주어가 실제로 할 수 없는 동작을 하는 문장을 평서문으로 고칩니다.

| 전 | 후 |
|---|---|
| 단일 velocity MSE로 요약하면 이 설계를 놓친다 | 단일 velocity MSE로 요약하면 두 CE 항이 빠진다 |
| 이 순서로 읽으면 비교 기준이 갖춰진다 | 네 편은 각각 X를 다룬다. 9–12주 실험에서 비교 기준으로 쓴다 |
| 레인은 서로 다른 계열의 병존을 보여준다 | 레인은 서로 다른 계열의 문헌이 같은 시기에 발표됐다는 사실을 나타낸다 |
| 토큰의 정체성 가리기 | 토큰을 [MASK]로 바꾸는 손상 |
| 백본 공유가 표현 공유를 보장하지 않는다 | 백본을 공유해도 표현까지 공유하는 것은 아니다 |
| 데이터가 말해준다, 시장이 보상한다 | 데이터에서 X가 확인된다, 고객이 X를 선택했다 |

남기는 경우: 학술 관용 환유(`본 연구는 ~을 보인다`), 행위자 없는 자연 현상(`기온이 올랐다`),
소프트웨어가 실제로 하는 동작(`린터가 잡아낸다`). 원문에 없는 행위자를 지어내지 마십시오.

## L2-6. 해석을 뜻하는 `읽는다`

`~로 읽는다`, `~로 읽지 않는다`가 문서를 읽는 행위가 아니라 해석·분류를 뜻하면 고칩니다.

- `인과 비교로 읽지 않는다` → `인과 비교로 해석하지 않는다`
- `순서 분해로 읽는다` → `순서 분해에 해당한다`
- `세 모델을 같은 질문으로 읽는다` → `세 모델을 같은 기준으로 비교한다`

논문을 실제로 읽는다는 뜻(`읽기: DDPM → Score SDE`)은 남깁니다.

## L2-7. 의인화된 도식·차트 문구

도식과 차트 안의 짧은 문구도 같은 규칙을 적용합니다.

- `학습 때만 지나는 길` → `학습할 때만 사용`
- `모든 칸을 가로지르는 채널` → `모든 항목에 적용`
- `분기는 손상 한 곳에서만 생기지 않는다` → `연속·이산 구분은 ② 손상 방식만으로 정해지지 않음`
