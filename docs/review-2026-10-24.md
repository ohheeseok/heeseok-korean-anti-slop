# v1.0.3 모델 교차 검토 기록

검토일: 2026-10-24. 대상: heeseok-korean-anti-slop v1.0.2와 수정안.

## 검토 진행

| 검토 도구 | 진행 |
|---|---|
| Claude | 독립 검토 1회 + Gemini 보고서·수정안 교차 검토 1회 |
| Gemini | 독립 검토 1회 + Claude 보고서·수정안 교차 검토 1회 |

두 모델에 동일한 스킬 본문·레이어별 참고 문서·검사기·테스트를 제공했습니다. 여덟 개 실전 입력(A–H)의 교정도 요청해 문체뿐 아니라 의미 보존을 살폈습니다. 외부 모델은 파일을 수정하지 않았고 응답을 반환했습니다. 코드 변경과 최종 반영 판단은 응답을 검토한 뒤 별도로 수행했습니다.

## 채택한 지적

| 지적 | 반영 |
|---|---|
| ‘자리 두 개’를 ‘담당자 한 명의 두 역할’로 단정 | 문맥 확인 전 원문 유지. 실제 칸·손잡이·좌표계 예외를 SKILL과 L2에 명시 |
| 확인 메모가 교정 예시 본문에 섞임 | 출력 형식에 ‘확인 필요’를 추가하고 교정문 밖에 작성 |
| 문서 종류 미상 시 합니다체 전환, 평서를 의무로 변경할 위험 | 원문 어미 유지. 명령·의무·평서를 구분 |
| ‘만으로’ 추가로 기준 배제의 뜻이 약해짐 | CE 예시에서 ‘만’ 삭제, 원래 판정 동사 유지 |
| ‘보장하지 않는다’가 실제로 공유하지 않는다는 단정으로 변함 | 보장 불가의 뜻으로 교정 |
| 제목 ‘학습 모듈 일곱’이 ‘연구 영역 A–H’로 바뀜 | 선수지식 1개·모듈 7개라는 원래 개수와 구분 보존 |
| 연결어를 횟수로 삭제하는 규칙과 논리 보존 규칙의 충돌 | 실제 논리 관계를 나타내면 유지하고 기능이 중복될 때만 축소 |
| 압축 명사구 탐지가 특정 예문에 맞춰짐 | 한글 명사 조합 후보로 일반화하고 영문 약어 나열 제외 |
| 과거형 학술 보고도 원칙문 반복으로 표시 | L3-1은 현재형 종결 반복 후보로 한정. 종결어미 분포에서는 과거형 유지 |

## 재확인하거나 채택하지 않은 지적

- **참고 파일 누락 주장:** Gemini 입력에 `case-study-roadmap.md`를 생략했기 때문에 생긴 오판입니다. 실제 파일은 존재하며 두 모델의 교차 검토에 이 사실을 전달했습니다.
- **속격 예문이 0건이라는 주장:** 기존 검사기는 ‘기업의 데이터의 안전한’ 부분을 이미 탐지했습니다. 실제 미탐인 ‘모델의 안정적인 학습의 조건’처럼 첫 속격 뒤에 수식어가 있는 경우를 근거로 개선했습니다.
- **기술 문맥을 정규식으로 전부 자동 제외:** 칸·손잡이·좌표계의 실제 쓰임은 주변 몇 단어로 확정할 수 없어 후보를 표시하고 문맥에서 보존하도록 했습니다.
- **비용을 센다의 단일 정답:** 두 모델은 ‘집계’와 ‘산정’의 적합성을 다르게 판단했습니다. 문맥에 따라 계산·집계·산정·측정을 선택하도록 했습니다.
- **조사·지시어 추가를 모두 의미 훼손으로 보는 판단:** 실제 주장·조건·범위가 달라지는지를 기준으로 삼습니다. 자연스러운 한국어로 고치는 데 필요한 조사·지시어 수정 자체를 금지하지 않습니다.

## 검증과 적용 범위

- CLI 회귀 테스트 7개를 통과했습니다. 사용자 예문 8개, 다른 압축 명사구, 영문 약어 나열, 과거형 보고, 인용문 제외와 입력 파일 불변성을 확인합니다.
- 스킬 형식과 문서 링크를 확인했습니다.
- [실제 교정 행동 점검 사례](../references/behavioral-checks.md)에 의미 보존 기준을 남겼습니다.

독립 검토에서는 Claude의 과도한 어미 변경과 Gemini의 ‘선행 연구’ 추가도 확인됐습니다. 모델 간 동의를 합격 기준으로 삼지 않고 원문과 대조해 판단했습니다. 이 작업은 제한된 예시의 검토와 회귀 검사이며 일반 문서 전체의 교정 성능을 수치로 평가한 결과는 아닙니다.
