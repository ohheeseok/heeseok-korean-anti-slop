# 초보자용 1차시 강의의 AI 문체 분석

검토일: 2026-10-24. 반영 버전: heeseok-korean-anti-slop v1.0.4.

## 검토 범위

본문 `body.html`, 배포본 `index.html`의 11개 슬라이드 텍스트를 확인했습니다. `OUTLINE.md`, `REVIEW.md`, `OUTLINE-ICONS.md`는 구성 의도와 화면 문구를 구분하는 보조 자료로 읽었습니다. 문체와 표현의 역할을 분석했으며 제품의 현재 기능·구독·OS 지원 주장을 외부 검증한 결과는 아닙니다.

이번 자료의 특징은 거창한 한자어·홍보 문구보다 **쉬운 단어로 실제 기능·조작 대상을 대신하는 은유와 짧은 반전형 결말**입니다. 문장 하나가 자연스러워도 ‘손→자리→층’으로 설명을 이어 가면서 학습자가 실제 대상과 다시 연결해야 하는지 살펴볼 필요가 있습니다. 이는 작성자의 편집 선호에 따른 검토이며 구어체 자체의 오류 판정이 아닙니다.

## 주요 사례

| 위치 | 실제 문구 | 판단과 스킬 반영 |
|---|---|---|
| 표지 | 챗봇은 알려만 주고, 얘는 해준다 | ‘얘’가 가리키는 도구를 확인. 친근한 어미 자체는 문제가 아니며 실제 기능명이 필요한 위치인지 검토. L1-11 |
| 4장 | 챗봇은 몰라서 못 한 게 아닙니다. 손이 없어서 못 한 겁니다. | 반전 뒤의 신체 비유가 실행 조건 설명을 대신함. 권한·도구 연결 상태를 추측하지 않고 무엇이 불가능했던 시연인지 확인. L2-8 |
| 5장 | 같은 앱 안에 다른 자리가 있습니다 / 자리를 옮깁니다 | ‘자리’가 화면·기능·도구 전환을 뜻하는지 확인하고 원문에 있는 이름과 연결. 앱·설치 방법에 관한 새 설명을 만들지 않음. L1-11, L2-8 |
| 6·7장 | 사고가 나도 되는 상태 / 좁은 폴더 / 사고 반경 | 구체적인 복사본 준비·작업 대상 폴더 지정이 주변에 제시돼 있음. 그 조치를 직접 설명하되 사고가 허용된다는 의미로 넓히지 않음. L2-8, L3-7 |
| 8장 | 말은 그대로인데 결과가 달라졌습니다. 바뀐 건 자리입니다. | 같은 입력과 다른 결과는 실제 비교 정보. 다만 ‘자리’ 한 단어로 실행 경로·폴더 지정 조건을 대신하는 결말은 검토. 한 시연을 모든 챗봇의 기능으로 일반화하지 않음. L2-8 |
| 9장 | 1층에서 부탁하기 / 3층으로 옮기고 폴더 지정하기 | 행위 지시를 비유적 층수로 표기. 실제 기능명과 대응을 확인. 물리적 층수·전문 계층 모델은 예외. L2-8 |
| 10장 | 되돌릴 수 있으면 성공입니다 / 되돌려 보지 않았다면 아직 성공이 아닙니다 | 교훈형 제목·결말이지만 이 장에서는 실제 완료 기준이기도 함. 표현을 다듬어도 되돌리기 확인이라는 필수 조건은 보존. L3-7 |
| 구성 문서 | 오늘의 목표는 이해가 아니라 목격이다 | 기획 문서의 수사이며 화면의 동일 문장으로 보고하지 않음. 실제로 보여 주는 수업 방식과 허위 양자택일의 구분이 필요. L1-5의 문맥 판단 |

‘자리’와 ‘층’의 대응이 강의 전체에서 정의되지 않았다고 단정할 수는 없습니다. 아웃라인은 0차시를 이미 들었고 관련 화면을 띄워 본 학습자를 전제로 합니다. 제공되지 않은 0차시 내용은 검토하지 않았습니다. 정의된 별칭이더라도 실제 행동 지시를 기능명과 함께 쓰는 것이 작성자의 선호에 맞는지 점검할 수 있습니다.

## 원문에 적용하지 않은 개선 예시

아래는 스킬의 판단 기준을 설명하기 위한 예시이며 강의 파일을 수정한 결과가 아닙니다.

| 원문과 확인된 문맥 | 평이한 표현 예시 | 보존 조건 |
|---|---|---|
| 좁은 폴더만 지정합니다. 주변에서 실습용 복사본 폴더를 지정함 | 실습용 복사본 폴더만 지정합니다. | 작업 범위 제한을 나타내는 ‘만’ 유지 |
| 사고가 나도 되는 상태를 만듭니다. 뒤에 복사본·변경 전 목록을 안내 | 실습용 복사본과 변경 전 목록을 준비합니다. | 나머지 작업 범위·중단 절차도 유지 |
| 되돌려 보지 않았다면 아직 성공이 아닙니다. 완료 조건으로 제시 | 되돌리기를 확인하기 전에는 실습이 완료되지 않습니다. | 필수 확인을 단순 권고로 바꾸지 않음 |

‘손이 없다’는 비유를 특정 권한 상태로 단정하거나 ‘자리를 옮긴다’를 임의의 제품 이동 경로로 바꾸는 예시는 만들지 않았습니다. 해당 정보는 문체 규칙만으로 결정할 수 없습니다.

## 보존할 표현과 구조

- `복사본으로 작업합니다`, `바꾸기 전 목록을 저장합니다`, `선택된 폴더 이름을 다시 봅니다`: 구체적인 대상과 행동이 있습니다.
- `화면이 다르면 멈추고, 바로 옆 사람과 함께 확인합니다`: 실제 조건과 행동을 전달합니다. 반복된 당위라는 이유로 삭제하지 않습니다.
- `이런 폴더, 있으시죠`, `직접 해보겠습니다`: 질문과 실습 예고의 기능이 분명합니다. 모든 제목을 딱딱한 명사형으로 바꾸지 않습니다.
- 3·8장의 같은 요청 문장: 입력 동일성이 비교 조건이므로 글자를 바꾸지 않습니다.
- 챗봇 말풍선의 `물론입니다`와 OS별 안내: 시연용 인용으로 구분하며 교안 작성자의 직접 말투와 섞어 집계하지 않습니다.
- 6·7·10장의 복사본·범위 제한·중단·복구: 절차와 완료 조건을 유지합니다.

## 검사기와 검증

기존 v1.0.3 검사기는 이 본문에서 연결어미 뒤 쉼표 6건만 표시했고, 신체·공간 은유는 표시하지 못했습니다. v1.0.4의 L2-8 규칙은 손 비유 1곳, 앱·자리 표현 2곳, 층수로 쓴 실습 지시 2곳을 검토 후보로 표시합니다. 이는 어휘 후보 수이며 문체 품질 점수나 오류 개수가 아닙니다.

L1-11의 지시 대상, 시연용 인용 경계, 앞뒤 장의 대응, L3-7의 완료 조건은 기계 탐지로 확정하지 않습니다. 사람의 문맥 검토가 필요합니다. 테스트는 새 후보의 탐지와 물리적 층수·실제 손잡이·구체 절차 등 대조 문장의 L2-8 미표시를 포함하며, 기존 검사까지 총 9개를 통과했습니다.

입력 자료는 읽기 전용으로 분석했고 스킬·참고 문서·검사기·점검 사례만 업데이트합니다. 원본 강의 전체와 내부 지시서는 저장소에 복사하지 않습니다.

분석 전후 원본 폴더의 17개 파일을 SHA-256으로 대조했으며 모든 파일의 내용이 동일했습니다.
